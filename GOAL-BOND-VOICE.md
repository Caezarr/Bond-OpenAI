# Bond-OpenAI Voice goals — index

The original combined goal has been split into two independent contracts:

- [GOAL-BOND-MCP.md](GOAL-BOND-MCP.md) — local MCP, Bond task classification,
  Fredo execution, safety, callbacks and software acceptance gates.
- [GOAL-BOND-DESIGN.md](GOAL-BOND-DESIGN.md) — website, slide deck, visual
  identity, demo narrative and design acceptance gates.

The Bond execution path is local. Users clone the repository, bootstrap it and
start the MCP. GitHub is only the distribution channel; no hosted marketplace
or deployment service is a runtime dependency for Bond voice tasks.
